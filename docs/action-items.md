## 最近一轮做了什么

**alpha.3（手势与首帧）**：报告的六个问题都不在静态截图里。最要紧的一条是拖动——此前所有"可拖动"的控件，无论手指移多远，位移都被橡皮筋限制在十几像素内，看着像控件朝手指歪了一下而不是被带着走；形变也一开始拖就顶到上限，所以每次都一模一样。现在控件在自身行程内 1:1 跟手，形变来自速度与阻力。另外修掉了融合层交还画笔时的跳变、共享表面上主操作按钮没有底色（浅色下白字画在透明上）、导航链接触发浏览器原生拖拽、首帧回弹、浅色底色过亮，以及行进高光在指针越过左边缘时整圈乱转。详见 `../reports/hig-review.md` 第〇节。

**alpha.2**：把仓库展平成可发布的单包，修掉用户实测报出的七组缺陷，把组件页改成可查阅的形态、把全站文案换成面向使用者的说法，补齐逐组件的测试与审计。顺带修掉两个会让包在真实项目里直接用不了的问题：首屏主题脚本违反 CSP，以及打包过程丢掉了 `"use client"`。

## 下一位接手者的第一轮工作

1. 跑 `accessibility.md` 第 8 节的人工项——真实屏幕阅读器，以及玻璃在真实照片上的实际对比度。这两项是目前最大的未知。
2. 在触摸真机上过一遍拖动手感：`touch-action` 的判定、手指遮挡、甩动惯性，都不是鼠标能替代的。
3. 在 Windows / Linux 与不同硬件加速设置上重跑 `pnpm test:chrome`，再决定是否默认开启 SVG 折射。
4. 真正发一次 npm 包，并在一个空项目里装回来验证。
5. 用 DevTools 录制替换经验预算，确认「一屏二十块玻璃」在低端设备上是否成立。
