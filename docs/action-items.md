## 本轮（0.2）做了什么

先落地 token 体系与材质引擎，再按层重排组件目录并补齐 HIG 核心组件，然后把文档站用这套组件自身重建，最后重写测试。顺序是刻意的：地基不先定下来，后面每个组件都会各自发明一套数值。

审计出并修掉的主要问题：玻璃被用进内容层、整面高光渐变与双层斜面、缺少语义色与字号体系（站内大量 8–10px 文字）、缺少 `prefers-contrast` 支持、滑块旋钮常驻玻璃、命中区不足 44px、物理属性导致 RTL 破版、自定义栏背景与边框、主题闪烁且不响应系统深色模式。

## 下一位接手者的第一轮工作

1. 跑 `docs/accessibility.md` 第 8 节列出的人工项——真实屏幕阅读器与实际合成背景的对比度，是目前最大的未知。
2. 在 Windows / Linux 与不同硬件加速设置上重跑 `npm run test:chrome`，再决定是否开启 `enableSvgAuto`。
3. 做依赖安全审计并在 CI 上验证可重现构建。
4. 用 DevTools 录制替换 rAF 诊断，确认 20 个折射元素的预算在低端设备上是否成立。
