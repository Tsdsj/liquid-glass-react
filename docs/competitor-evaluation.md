# 现有内核对照：待实测项目

## 已知与未知

原报告要求在同一场景比较 CSS、rdev、Liqui Design 与自研小原型。当前只实际运行了本项目 CSS、SVG 与不透明路径；**没有安装运行 rdev 或 Liqui Design**，没有它们的截图、成本数字或稳定性排名。

公开参考：`https://github.com/rdev/liquid-glass-react`、`https://github.com/leefanv/liqui-design`、`https://github.com/shuding/liquid-glass`。公开描述、许可与定位参考原始报告，正式复用必须固定实际版本/提交并再次核查 LICENSE 和依赖。当前项目不包含上述项目源码。

## 对照方案

保留 `StressBackground` 中相同背景，在相同 Chrome、视口、DPR、硬件和加速设置下分别放入候选内核。使用相同外框尺寸和前景内容；先校准模糊程度、底色和边缘强度，再比较成本，避免让更透明、更高噪声的效果天然更“醒目”。

## 执行步骤

在独立分支安装和固定候选版本，先检查许可，再建立最薄的适配层。不要把未核实的 npm 包名或 README 示例硬写进默认启动链路。每个候选至少检查 regular/clear 用途、圆角矩形/胶囊、文字清晰度、动态背景、祖先 filter/mask、卸载清理与严格 CSP。

记录版本/提交、原始参数、截图、DevTools trace 和失败条件。只有发现可复现的上游限制，才决定继续独立内核还是 fork。当前自研实验不构成“更优方案”结论。
