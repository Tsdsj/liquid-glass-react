# 设计系统 v0.2

参照 Apple 的 HIG 与 Liquid Glass 指南整理。下列数值是本项目的实现取值，**不是** Apple 的官方参数；来源与引用见 `original-research.md`。

## 1. 两层结构：这是整套系统的地基

| | 内容层 | 操作 / 导航层 |
| --- | --- | --- |
| 是什么 | 正文、列表、卡片、表单、媒体、页面背景 | 工具栏、标签栏、侧边栏、导航栏、sheet、菜单、提示框、浮动按钮 |
| 用什么 | 实色分组背景，或 `MaterialView` 的标准材质 | Liquid Glass |
| 组件 | `Card` `List` `MaterialView` `Text` `Divider` | `GlassSurface` `GlassToolbar` `TabBar` `Sidebar` `GlassSheet` … |

三条不能违反的规则：

1. **玻璃不进内容层。** 满屏半透明卡片是最常见的"不像 Apple"的写法。唯一例外是内容层里的**瞬时控件**——滑块与开关的旋钮只在被操作时抬升为玻璃，静止时保持安静。
2. **不要玻璃叠玻璃。** 放在玻璃上的元素用填充、透明度和 vibrancy，不再叠一层玻璃。工具栏里相关的项**共享一个** `ToolbarGroup` 背景。
3. **克制使用。** 把玻璃留给最重要的功能元素；到处都是就等于没有。

## 2. 小玻璃与大玻璃

尺寸会改变材质本身的行为，这不是同一个效果的两种大小。

| | `size="small"` | `size="large"` |
| --- | --- | --- |
| 用于 | 按钮、标签栏、工具栏 | 侧边栏、菜单、sheet、浮层、提示框 |
| 模糊 | 14px | 40px |
| 底色不透明度 | 0.70 / 0.78（浅 / 深） | 0.86 / 0.90 |
| 阴影 | `--lg-glass-shadow` | `--lg-glass-shadow-large`（更深） |
| 明暗翻转 | **随背景翻转** | **不翻转**——这么大的表面跟着内容翻转会没法读 |

浮层组件已经自动使用 `large`，一般不需要手动指定。

## 3. Regular 与 Clear

| | regular | clear |
| --- | --- | --- |
| 使用位置 | 默认。栏、侧边栏、菜单、文字较多的表面 | 只用于媒体内容之上，且上层内容本身明亮醒目 |
| CSS blur 起点 | 14px（small）/ 40px（large） | 1.5px / 6px |
| 饱和度 | 1.15 / 1.30 | 1.08 / 1.12 |
| 默认位移 scale | 18 / 26 | 32 / 40 |
| 边缘影响带 | 16 / 22 CSS px | 18 / 24 |
| 亮背景 | — | 叠加一层 35% 暗化 |
| 未知背景（`tone="mixed"`） | 保守底色 | **自动降级为 regular** |

**两者不在同一个界面里混用。**

## 4. 背景色调：声明，不采样

`AGENTS.md` 禁止 DOM 截屏与跨源像素读取，所以"小玻璃随背景翻转"不是自动猜的，而是由区域声明、后代继承：

```tsx
<GlassBackdrop tone="dark">
  <video … />
  <GlassToolbar aria-label="播放控制">…</GlassToolbar>
</GlassBackdrop>
```

`tone="mixed"` 是安全默认值：未知背景保持应用外观，并把 `clear` 退回 `regular`，而不是赌一把。

## 5. 光是被折射的，不是画上去的

材质由三样东西定义：**折射**、**一条发丝边**、**干净的内部**。

- 高光是一条由指针角度驱动的 conic 描边，**绕着轮廓行进**，而不是固定在上边缘。
- 没有整面扫过的白色渐变，没有第二层斜面，没有过粗的亮描边。这些会把材质变成 2008 年的光泽塑料按钮，而且在纯色背景上最难看——那里根本没有东西可折射。
- 提亮用 `--lg-glass-contrast: 1.05` 重新拉开背景层次，而不是 `brightness()`，后者只会把材质洗白。
- `chroma` 打开色散（三通道分别位移）。成本约三倍，只用于少数非固定元素。

## 6. 形状：三类，不是一堆数字

| 类型 | 半径 | 用于 |
| --- | --- | --- |
| 固定 | 常量 | 不涉及嵌套的独立组件 |
| 胶囊 | 高度 / 2 | 按钮、栏、分段控件、开关 |
| **同心** | 容器半径 − 内边距 | 任何嵌套在圆角容器里的形状 |

内圆角过大会"掐角"，过小会"喇叭口"。两种都很显眼。

```tsx
<Card radius={26} padding={12}>
  <Concentric minimum={8}>…</Concentric>   {/* 26 − 12 = 14 */}
</Card>
```

也会独立出现的组件要传 `minimum` 作为兜底。JS 侧用 `concentricRadius(26, 12, { minimum: 8 })`。

半径 token：`--lg-radius-xs/s/m/l/xl/xxl` = 6 / 10 / 14 / 20 / 26 / 34，`--lg-radius-sheet` 38，`--lg-radius-window` 24。

## 7. 排版

iOS 文本样式全表，字号、行高、字距由样式一起决定：

| 样式 | 字号 / 行高 | 字距(em) |
| --- | --- | --- |
| largeTitle | 34 / 41 | +.012 |
| title1 | 28 / 34 | +.014 |
| title2 | 22 / 28 | −.012 |
| title3 | 20 / 25 | −.023 |
| headline | 17 / 22 semibold | −.026 |
| body | 17 / 22 | −.026 |
| callout | 16 / 21 | −.020 |
| subhead | 15 / 20 | −.016 |
| footnote | 13 / 18 | −.006 |
| caption1 | 12 / 16 | 0 |
| caption2 | 11 / 13 | +.006 |

- **11pt 是可读下限**，界面里没有任何文字低于它。
- Dynamic Type：根节点 `data-lg-text-size="xs…xxxl, ax1…ax5"`，整套比例缩放。AX5 下布局必须仍能回流。
- 分区标题用**标题式大小写**，不再用全大写。提示框、sheet、引导页的标题**加粗且左对齐**。
- 负字距是为拉丁文设计的，CJK 语境下自动关闭。
- SF 字体不能自托管到网页（许可只覆盖 Apple 平台应用）。`-apple-system` 只在 Apple 设备解析为 SF，其他平台落到 Segoe UI / Roboto，因此字号用 px 定死并在这些平台复核行长。

## 8. 色彩

- 12 个系统色（red…brown）× 浅色 / 深色 / **增强对比度**三套取值，外加 gray1–6。
- 语义色阶：`--lg-label` / `-secondary` / `-tertiary` / `-quaternary`、`--lg-separator`、`--lg-fill`(1–4)、`--lg-bg`(1–3)、`--lg-bg-grouped`(1–3)。
- `--lg-accent` 默认系统蓝，只用于**唯一的主操作**与选中态。换品牌色只改这一对 token：

  ```css
  :root, [data-lg-theme="light"] { --lg-accent: #6d28d9; }
  [data-lg-theme="dark"]        { --lg-accent: #8b5cf6; }
  ```

- 玻璃没有固有颜色。着色只加在主操作的**背景**上，标签保持白色；栏上的符号与文字默认单色。
- 开关打开态按 HIG 固定为**系统绿**，不跟随品牌色。
- 颜色不能是唯一的信息载体。

主题是**按元素**声明的：Provider 在每个表面写 `data-lg-theme`，所以浅色页面里可以放一条深色工具栏。这也是 token 用属性选择器分组而不是 `light-dark()` 的原因。

## 9. 尺寸与间距

4pt 栅格（`--lg-space-1…10`）。页边距 16pt（紧凑）/ 20pt（常规）。可读正文宽度 672pt。

命中区不小于 **44×44pt**，控件间距不小于 8pt。视觉可以更小，命中区不行——粗指针设备上按钮用伪元素把命中区补回来。

密度：compact 控件高 36px、圆角 12px；comfortable 44px / 18px。

## 10. 动效

按下 90ms，松开 220ms，布局 280ms，弹簧总时长 520ms，浮层 360ms。三条 `linear()` 曲线由阻尼振子采样得到。

- **在按下时响应**，不是抬起时；拖动过程中 1:1 连续反馈；动画随时可被抓住并改变方向。
- 菜单、浮层、操作表、sheet 从**打开它们的控件**里长出来并保持锚定。
- **控件是可以拖的**：分段控件按住选中项滑动、开关可以甩、滑块跟随手指；都会随拖动拉伸并弹簧归位，选择在拖动**过程中**更新。只能点击的实现是最常见的破绽。
- 只动 `transform` 与 `opacity`。永远不要动画 `backdrop-filter`、`blur()`、`box-shadow` 或 `width`。
- 不要给所有玻璃加 `will-change`；只提升正在运动的那一个。单视图折射元素控制在 20 个以内。

## 11. 使用禁区

不要把完整组件根节点送进扭曲滤镜；不要给所有组件加 `contain: paint` / `will-change` 当作通用优化；不要把所有玻璃面变成持续流动的水波。实际效果受支持形状、背景采样边界和设备预算限制。

## 12. 修改 token

结构化的材质 / 密度 / 文本样式参数在 `packages/tokens/src/index.ts`；颜色、字号、间距、形状、时长在 `packages/tokens/src/tokens.css`。局部换品牌色覆盖明确主题选择器中的 `--lg-accent` / `--lg-accent-contrast`，不要依赖无界的全局 button 选择器。
